CSS Properties Reference

CSS properties are used to control the appearance and layout of HTML elements.

Property Description Example
color Sets the text color. color: red;
background-color Sets the background color. background-color: blue;
font-size Sets the size of text. font-size: 20px;
margin Sets the outer spacing of an element. margin: 10px;
padding Sets the inner spacing of an element. padding: 10px;
border Creates a border around an element. border: 1px solid black;
