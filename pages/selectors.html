CSS Selectors Reference

CSS selectors are used to select HTML elements that we want to style.

Selector Description Example
Element Selector Selects all elements of a particular type. p { color: blue; }
Class Selector Selects elements with a specific class. .box { color: red; }
ID Selector Selects an element with a specific ID. #header { color: green; }
Universal Selector Selects all HTML elements. * { margin: 0; }
Group Selector Selects multiple elements. h1, p { color: black; }
