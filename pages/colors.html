CSS Color Reference

CSS provides different ways to specify colors for HTML elements.

Color Method Example Description
Color Name red Uses predefined color names.
HEX #ff0000 Uses hexadecimal values.
RGB rgb(255, 0, 0) Uses red, green and blue values.
RGBA rgba(255, 0, 0, 0.5) RGB color with transparency.
HSL hsl(0, 100%, 50%) Uses hue, saturation and lightness.
