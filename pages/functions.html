CSS Functions Reference

CSS functions perform calculations or provide special values that can be used in CSS properties.

Function Description Example
rgb() Defines a color using red, green and blue values. color: rgb(255, 0, 0);
rgba() Defines a color with transparency. color: rgba(255, 0, 0, 0.5);
calc() Performs calculations. width: calc(100% - 20px);
url() Specifies a resource such as an image. background-image: url("image.jpg");
var() Uses a CSS custom property. color: var(--main-color);
